## Contract and prerequisites

One application-facing `CanonicalResultDocument`, wire schema 7, with a shared envelope
and discriminated mathematical answer kinds. Producers select kinds, not versions.
Ordinary mathematical leaves require producer-owned standard MathJSON. Binding, units,
special-function identity, Equation sets and formal logarithm semantics remain typed
data; LaTeX is derived presentation. Schema validation never replaces native proof.
The new implementation lives temporarily in `src/lib/result-contract/current/` and
unversioned `canonical-result-{common,current,equation,integration,special}.ts` types.
The old API remains in use until each consumer/producer migration passes. Temporary
coexistence is an implementation checkpoint, not a historical-format feature.

Prerequisites already present: bounded clone-safe JSON inspection; standard MathJSON
validation; producer proof ownership; domain printers; exact Integration kernels and
codecs; Equation projection/replay; separate workspace runtimes and OOE lifecycle.
Prerequisites this program supplies: common semantic authority, native evidence for
remaining string-only outputs, current action handling, persistence reset and new
exponential projection/lowering. A missing native leaf blocks its route's migration;
do not reparse printed mathematics, drop a route or relabel mathematics as text.

## Semantics to preserve

- Ordinary answers and math-bearing errors; compound period/phase, map profiles and
  independence; exact detail rows and row operations; undefined table cells; angles.
- Named special-function expression trees, including piecewise conditions.
- Equation's six outcomes, twelve set kinds, root isolation, integer/free parameters,
  parameter assumptions, domain and verified/unconfirmed distinctions.
- Rational all-roots local-complex primitives with captured-variable protection and
  exact source/input/primitive/norm conditions.
- Exponential construction records the entire rational exponent, including constants,
  and a fresh generator. Field expressions and all-roots logarithms bind it explicitly.
- Completed non-elementarity records subject, class and checked residue/Laurent
  obstruction. It is distinct from unsupported, invalid, failed proof and exhaustion.
- Ordinary rational answers may retain source restrictions from canceled exponential
  families. These use exact standard `Exp` trees with explicit provenance, independent
  of the final answer's surviving generator.

## Exponential adoption

Use the existing editor and workspace worker for one explicit indefinite integral.
Lower raw parser trees without rounding exact finite literals. Accept rational
operations, integer powers and `exp(r)`/`e^r` with rational r in the differential's
variable. Binding e makes e the variable; `exp(e)` remains unambiguous. Reject 0^0,
identically zero divisors and unsupported structures; retain restrictions even through
cancellation. Run checked general exponential normalization before choosing rational
or certified single-family integration. Surviving independent families, constant
extensions, nested exponentials, log input and symbolic parameters stay unsupported.

One cumulative context covers lowering through exact projection. Preserve Stop,
supersession, edit invalidation, stale replies, independent tabs, drafts and limits.
Keep compact/full root-log views, self-contained copy, conditions/provenance and
verified-negative details. Render exponentials as superscript e^{r(x)} on screen and
in copied LaTeX, not function-call exp(r) notation. Standard MathJSON Exp remains
the structured mathematical representation; the integration printer derives this
notation. Large expressions may use an explicit definition t = e^{r(x)}. Current saved problems contain
request, normalization certificate and tagged decision; replay never regenerates the
decision. Current-input comparison uses checked generator correspondence, including
full exponents, and current source exclusions.

A fully verified, authority-valid answer survives only an export artifact over 16 MiB,
with an export-unavailable notice. Proof failure or oversized canonical results still
fail closed. Imports stay at 16 MiB and source at 64 KiB.
