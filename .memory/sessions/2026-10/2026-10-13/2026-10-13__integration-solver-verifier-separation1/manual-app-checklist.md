## What is achieved now

Current rational/one-family exponential Integration shows its actual computed mathematics before final checking, then marks it Verified before preparing the downloadable file. All completed private decision backends have candidate/check APIs. Broader input adoption is unchanged.

## Manual app steps and expected results

1. Open Calculus → New Integration; integrate 1/(x²+1). The root-log answer includes C, complete definitions and source/input/norm conditions. During checking it is explicitly Not checked yet (brief for fast inputs), then Verified.
2. Switch compact/full formulas and copy. The complete mathematics/restrictions remain; copying during checking gives an unchecked notice without inserting that notice into the copied formula.
3. When verification is stopped, the candidate remains Not checked; it must not become a verified result. On checking failure it is withdrawn. Automated controlled-delivery screenshots cover these short-lived states.
4. After Verified, file preparation has its own status. Stop while preparation runs: the answer stays verified and file unavailability is reported. Export is enabled only when the file is ready.
5. Integrate e^x/x. A proposed negative is explicitly unchecked until its certificate passes; the resulting negative is Verified. No execution stop may be mistaken for this conclusion.
6. Edit/restart/close/switch tabs while work runs. Late results cannot replace the new request; switching alone and presentation changes leave work running. Opening a saved file creates its tab only after checked replay.

Performance speedups, readable proof presentation, symbolic input parameters and wider exp/log/algebraic input adoption are not asserted by this gate.
