## What Is Achieved Now

- Smooth non-periodic transcendental/radical numeric-ready equations can show validated approximate real roots through bounded auto-search when exact routes miss.
- Periodic-only selected-target expressions remain interval-first to avoid accidental fixed-window enumeration.

## Manual App Steps

- Enter `ln(x)+x=2` in Equation, Real, Exact, and run.
- Enter `sqrt(x+1)+e^{-x}=2` in Equation, Real, Exact, and run.
- Enter `sin(x)+cos(x)=0` in Equation, Real, Exact, and run if exact symbolic cannot close.
- Optionally enable Numeric Interval for periodic examples and run on a finite interval.

## Expected Results

- `ln(x)+x=2` returns an approximate root near `x ~= 1.557146`, with log-domain evidence.
- `sqrt(x+1)+e^{-x}=2` returns approximate roots near `x ~= 0` and `x ~= 2.74784`, with root-domain evidence.
- Periodic-only examples do not fall into broad bounded auto-search; they ask for a finite real interval when exact symbolic output is unavailable.
