# Sessions

- `sessions/` stores task dossiers.
- Create one folder per meaningful task using `YYYY-MM/YYYY-MM-DD/YYYY-MM-DD__short-slug`.
- Each session folder should contain:
  - `completion-report.md`
  - `commit-log.md`
  - `verification-summary.md`
- Each dossier file should start with an `## Attribution` block that follows `.memory/PROTOCOL.md`.
- Use sessions for task-specific detail that would clutter the daily journal.
- Keep the journal and sessions together:
  - journal = chronological stream
  - sessions = task dossier
- Do not add root-level dated session folders; use the month/day folder for the task date.
- Every journal month with completed milestone work should have a matching session month.
- Closely related slices may share one session dossier, but the dossier should link to the relevant journal/checklist/source records.
