# LibreOffice research parking spot

This folder is reserved for Notebook editor-interaction study against
LibreOffice. The local source mirror lives under ignored `mirror/` payload
directories; committed files here are metadata and research notes only.

Research should focus on interaction models rather than feature lists:

- image sizing and crop handles;
- drag/reposition behavior;
- anchoring and wrapping models;
- selection outlines and object frames;
- export/save interaction flow;
- responsiveness and input-latency architecture.

The current captured source context is recorded in
`../metadata/libreoffice.yaml`.
