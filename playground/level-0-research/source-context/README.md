# Source Context Research

This lane studies external systems as context only.

Source-context experiments may read ignored mirrors under `playground/sources/mirrors/<mirror-id>/`, but committed research artifacts must contain only:

- source paths and summaries
- benchmark or challenge families
- Calcwiz-native translation proposals
- boundary and contamination notes

They must not import, execute, depend on, or copy external mirror implementation code into stable Calcwiz.
